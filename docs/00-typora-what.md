# 0. 「和 Typora 一样」具体指什么

先把功能拆开。全部做完是一个产品；做子集也能叫 Markdown 编辑器，但手感差一截。

## 0.1 必须有（没有就不像）

| 能力 | 说明 |
| --- | --- |
| 所见即所得 | 不左右分栏。标题、粗体、列表在光标离开语法时显示成排版后的样子 |
| 源码仍在 | 磁盘上永远是普通 `.md`，用别的编辑器打开还能读 |
| 本地文件 | 打开/保存/另存为；改磁盘上的文件，不是云笔记 |
| 大纲 | 按 ATX/`#` 标题生成目录，点击跳转 |
| 图片 | 相对路径、拖拽进文档；文件拷到笔记旁或保持原路径 |
| 断网 | 主题、高亮、公式、流程图用包里的 JS/字体，禁止 CDN |

## 0.2 很像 Typora、可第二期做

| 能力 | 说明 |
| --- | --- |
| 数学 | `$…$` / `$$…$$`，本地 KaTeX |
| 图 | Mermaid、可选 flowchart |
| GFM | 表格、任务列表、删除线、围栏代码 + 高亮 |
| YAML front matter | 文首元数据，编辑区可折叠 |
| 导出 | HTML / PDF（macOS 可走打印面板）；Word 另说 |
| 主题 | CSS 换肤，离线 |
| 侧栏文件树 | 打开一个文件夹当工作区 |
| `.md` 关联 | 双击用 showMD 打开 |

## 0.3 不是同一类产品（别一上来做）

| 产品 | 差别 |
| --- | --- |
| Obsidian | 知识库、双链、插件市场；壳是 Electron，默认也本地，但产品形态更重 |
| VS Code | 程序员编辑器 + 预览，不是 WYSIWYG |
| iA Writer / Bear | 原生体验好，语法高亮为主，不是 Typora 那种「打完就变成文档」 |
| 纯预览器 | Quick Look / MacMD Viewer：只读 |

showMD 的定位建议：**本地 WYSIWYG Markdown 编辑器**，文件就是文件夹里的 `.md`。不做同步、不做账号、不做插件商店。

## 0.4 Typora 自己用什么（避免选错参照）

- **0.9.x**：Electron，所以网上长期说「Typora = Electron」。
- **现行 Mac 版（约 1.14，2026）**：Xcode 打的 **Cocoa/AppKit** 通用二进制，链 **WebKit**，用 **WKWebView** 画文档；包里没有 Chromium / Node。体积大约数 MB 级主程序 + 资源。

要「装在 Mac 上又轻」，应对齐 **现行 Typora：原生壳 + 系统 WebKit**，而不是对齐它的史前 Electron 版。
